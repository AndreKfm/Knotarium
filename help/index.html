What you can do with it

Knotarium is self-hosted, visual workflow automation. You design an automation as a graph of nodes on a canvas — HTTP calls, database queries, file and email operations, AI steps, and inline C# — wire them together with conditions, loops and parallel branches, and start the result from a manual click, a schedule, a webhook, or a poller.

The whole product is one .NET process serving both the API and the user interface, storing everything in a single local SQLite file. There is no separate database server, no Node.js runtime, and nothing phones home.

Finding things quickly

  • The sidebar lists every page, grouped by topic.
  • Long pages have an outline on the right that tracks where you are.
Screens have no addresses

Knotarium's interface keeps its navigation state in the browser session rather than in the address bar, so individual screens cannot be bookmarked or linked. Throughout this documentation a location is written as a click path, like Settings › Capabilities, meaning: open the Settings tab in the header, then choose Capabilities in the list on the left.
