### Added
- Self-hosted, node-based workflow automation engine (HTTP, database, file, email,
  schedule, polling, and AI nodes) with inline C# and subflows.
- Visual React Flow editor: proximity auto-connect, insert-on-edge, undo/redo,
  snap-to-grid, multi-select align/distribute, version history/diff/restore.
- Docker Compose quickstart and a Windows installer (runs as a service) — see the
  [README](README.md).
