# Step 4 — B2.2: Transactional Suspension

## Goal
Implement atomic execution suspension inside the engine's `WorkflowExecutor.cs`. To respect our strict architectural invariants, the **ExecutionJournal remains the absolute, sole canonical source of truth**. Variable updates and suspension events must be written as journal entries. The database columns `ExecutionInstance.VariableState` and `ExecutionInstance.Status` are managed strictly as **cached projections** generated by replaying/folding the journal. To enforce this capability, we are building a dedicated **`JournalFoldService`** replayer.

---

## Invariant Alignment
* **Invariant 3.1 (Single Source of Truth):** No parallel serialized memory blobs/snapshots are permitted. The journal remains the sole source of execution truth.
* **Invariant 3.2 (Atomic Suspension):** Appending a `WorkflowSuspended` journal entry, updating the status projection to `Suspended`, and writing the `VariableState` projection must execute within a single atomic database transaction.
* **Canonical Rehydration**: The active in-memory variable state bag and overall run status are re-constructed by folding/replaying the sequential journal events, rather than treating database cache columns as source of truth.

## Proposed Changes

### 1. Create [JournalFoldService.cs](file:///d:/Private/Source/AknSideProjects/Automate/Backend/KnotGarden.Features/Execution/JournalFoldService.cs) [NEW]
Build the event-folding service:
```csharp
public sealed class JournalFoldService
{
    public (Dictionary<string, JsonElement> Variables, ExecutionStatus Status) FoldJournal(IEnumerable<JournalEntry> entries)
    {
        var variables = new Dictionary<string, JsonElement>();
        var status = ExecutionStatus.Pending;

        foreach (var entry in entries.OrderBy(e => e.CreatedAtUtc))
        {
            switch (entry.EventType)
            {
                case "WorkflowStarted":
                    status = ExecutionStatus.Running;
                    break;
                case "WorkflowSuspended":
                    status = ExecutionStatus.Suspended;
                    var suspendedData = JsonSerializer.Deserialize<SuspendedPayload>(entry.Payload);
                    if (suspendedData?.Variables != null)
                    {
                        variables = suspendedData.Variables;
                    }
                    break;
                case "WorkflowResumed":
                    status = ExecutionStatus.Running;
                    break;
                case "VariableUpdated":
                    var update = JsonSerializer.Deserialize<VariableUpdatePayload>(entry.Payload);
                    if (update != null)
                    {
                        variables[update.Key] = update.Value;
                    }
                    break;
                case "WorkflowCompleted":
                    status = ExecutionStatus.Completed;
                    break;
                case "WorkflowFailed":
                    status = ExecutionStatus.Failed;
                    break;
            }
        }

        return (variables, status);
    }

    private class SuspendedPayload
    {
        public string SuspendedNodeId { get; set; } = null!;
        public Dictionary<string, JsonElement>? Variables { get; set; }
    }

    private class VariableUpdatePayload
    {
        public string Key { get; set; } = null!;
        public JsonElement Value { get; set; }
    }
}
```

### 2. Implement Transactional Suspended Traversal in [WorkflowExecutor.cs](file:///d:/Private/Source/AknSideProjects/Automate/Backend/KnotGarden.Features/Execution/WorkflowExecutor.cs) [MODIFY]
When a running node indicates a suspension (e.g. webhook wait):
* Open an explicit EF Core database transaction:
```csharp
using var transaction = await _dbContext.Database.BeginTransactionAsync(cancellationToken);
try
{
    // 1. Create canonical Journal Entry containing the variables payload
    var journalEntry = new JournalEntry(
        Id: Guid.NewGuid(),
        ExecutionInstanceId: executionInstance.Id,
        EventType: "WorkflowSuspended",
        Payload: JsonSerializer.Serialize(new { 
            SuspendedNodeId = currentNodeId, 
            Variables = currentVariables // Canonical variables in journal
        }),
        PayloadVersion: "v2"
    );
    await _dbContext.JournalEntries.AddAsync(journalEntry, cancellationToken);

    // 2. Update ExecutionInstance cache projections (mirrored for fast queries)
    executionInstance.Status = ExecutionStatus.Suspended;
    executionInstance.VariableState = JsonSerializer.Serialize(currentVariables); // Cached projection column
    
    _dbContext.Entry(executionInstance).Property(e => e.Status).IsModified = true;
    _dbContext.Entry(executionInstance).Property(e => e.VariableState).IsModified = true;

    await _dbContext.SaveChangesAsync(cancellationToken);
    await transaction.CommitAsync(cancellationToken);
}
catch
{
    await transaction.RollbackAsync(cancellationToken);
    throw;
}
```
